# 🌍 Wanderlust 
link -> https://airbnbclone-j1a7.onrender.com/listings

Wanderlust is a full-stack **property rental and booking platform** inspired by Airbnb.  
It allows users to list properties, browse stays, and make bookings with a smooth and responsive user experience.

Built using the **MERN stack (MongoDB, Express, React, Node.js)**.

---

## 🚀 Features

- 🏠 User can list properties (host mode)
- 🔍 Browse and search stays
- 📅 Book available properties
- 👤 User authentication (Signup/Login)
- 🖼️ Upload property images
- ⭐ Reviews and ratings system
- 📍 Location-based listings
- 💳 Booking management system
